```text

                  └──────────┬───────────┘
```

### My engineering principles

| Principle | What it means |
|---|---|
| 🎯 **Product First** | Build for a real use case, not just a tech demo |
| 🧩 **Clean Systems** | Keep code understandable and maintainable |
| 🔐 **Security** | Authentication, authorization and validation matter |
| ⚡ **Performance** | Efficient APIs, queries and responsive interfaces |
| 🧪 **Testability** | Validate behavior before calling it finished |
| 📈 **Scalability** | Design with future growth in mind |
| 🚀 **Ship** | A project is more valuable when people can actually use it |
